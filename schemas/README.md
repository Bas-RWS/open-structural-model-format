# OSMF Schemas

JSON Schemas (draft 2020-12), normative together with the specification text.

| Schema | Specification |
|---|---|
| [core.schema.json](core.schema.json) | [core-objects.md](../specification/core-objects.md) |

Schemas check the structure of single objects. Rules that need the whole model, such as uniqueness, reference resolution, Group depth and List cycles, are checked by validators.
