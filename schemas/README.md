# OSMF Schemas

JSON Schemas (draft 2020-12), normative together with the specification text.

| Schema | Specification |
|---|---|
| [core.schema.json](core.schema.json) | [core-objects.md](../specification/core-objects.md) |
| [nodes.schema.json](nodes.schema.json) | [nodes.md](../specification/nodes.md) |

Schemas check the structure of single objects. Rules that need the whole model, such as uniqueness, reference resolution and List cycles, are checked by validators.
